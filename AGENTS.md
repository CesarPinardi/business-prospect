## Agent skills

### Issue tracker

Issues are tracked in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The repository uses the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

The repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.

### Pull requests

After every implementation task, once the production build passes, always commit the verified changes, push the task branch, and open a pull request targeting `main` with `gh pr create --base main`. Report the PR URL in the handoff. Keep the PR open; merge only when explicitly requested.
